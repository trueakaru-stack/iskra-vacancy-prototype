# Проверка

## Исходная библиотека NeoBook

В изолированной копии установка зависимостей выполнена с фиксированным lock-файлом. Сборка JavaScript полного пакета `@neobook/react` проходит, но собственная проверка типов полной библиотеки завершается ошибками `TS2375` при `exactOptionalPropertyTypes`. Диагностика затрагивает существующие компоненты, в том числе DataTable, Select и Sidebar. Исходные файлы библиотеки не исправлялись и исходный проект пользователя не изменялся.

По решению пользователя в проекте оставлены только выбранные компоненты NeoBook и связанные с ними исходники. Приложение будет проверяться вместе с ними; проверка остальных компонентов библиотеки не входит в объём задачи. Итог сборки и проверок приложения будет добавлен после реализации.

Первый запуск тестов приложения затронул также скопированные тесты полной библиотеки. Конфигурация исправлена: теперь запускаются только тесты прототипа. Четыре текущих теста прототипа проходят.

## Промежуточная проверка прототипа

- 14 тестов проходят: прогресс, сохранение текста, поиск и фильтр, сценарий вопросов, повторное открытие черновика, обработка результатов и ошибок речи на тестовых заменах, контракт Worker на тестовой модели.
- Проверка типов и production-сборка проходят. Сборка исходных токенов показывает предупреждения о контрасте; тёмная тема в прототипе не используется. Используемая светлая граница поля, воспроизводящая публичный экран «Искры», имеет расчётный контраст около 1,26:1 на белом и не достигает 3:1 для границы поля. Изменение значения требует согласования визуального расхождения.
- Тесты распознавания и Worker используют тестовые замены; работа с реальным микрофоном и реальной моделью ещё не подтверждена.
- Визуальное сравнение не выполнено: браузер отклонил открытие локального файла, локальный сервер без прямого запроса пользователя не запускается. Проверка будет выполнена на опубликованном предпросмотре, если размещение доступно.
