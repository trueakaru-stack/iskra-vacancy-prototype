# Проверка

## Исходная библиотека NeoBook

В изолированной копии установка зависимостей выполнена с фиксированным lock-файлом. Сборка JavaScript полного пакета `@neobook/react` проходит, но собственная проверка типов полной библиотеки завершается ошибками `TS2375` при `exactOptionalPropertyTypes`. Диагностика затрагивает существующие компоненты, в том числе DataTable, Select и Sidebar. Исходные файлы библиотеки не исправлялись и исходный проект пользователя не изменялся.

По решению пользователя в проекте оставлены только выбранные компоненты NeoBook и связанные с ними исходники. Приложение будет проверяться вместе с ними; проверка остальных компонентов библиотеки не входит в объём задачи. Итог сборки и проверок приложения будет добавлен после реализации.

Первый запуск тестов приложения затронул также скопированные тесты полной библиотеки. Конфигурация исправлена: теперь запускаются только тесты прототипа.

## Промежуточная проверка прототипа

- 15 тестов проходят: прогресс, сохранение текста, поиск и фильтр, закрытие окна по Escape и возврат фокуса, сценарий вопросов, повторное открытие черновика, обработка результатов и ошибок речи на тестовых заменах, контракт Worker на тестовой модели.
- Проверка типов и production-сборка проходят. Сборка исходных токенов показывает предупреждения о контрасте; тёмная тема в прототипе не используется. Пользователь согласовал затемнение границ полей: применено `oklch(66% 0 0)` на белом, расчётный контраст около 3,1:1. Проверка отрисованных состояний ещё необходима.
- Тесты распознавания и Worker используют тестовые замены; работа с реальным микрофоном ещё не подтверждена.
- 2026-11-04: развёрнутый Worker с привязкой `AI` дважды вернул HTTP 200 и четыре непустые секции на вымышленных ответах. Во втором примере разговорные формулировки были приведены к тексту вакансии без новых фактов. Эти примеры не гарантируют качество или достоверность модели на других вводах.
- 2026-11-04: в опубликованном интерфейсе пройден сценарий с четырьмя вымышленными текстовыми ответами: прогресс достиг 100%, реальная модель вернула четыре блока, правка сохранилась после сохранения и повторного открытия черновика. Дополнительное введённое предложение сохранилось отдельно. Микрофон при этой проверке не использовался.
- Браузер отклонил открытие локального файла, поэтому визуальная проверка проводится на опубликованном предпросмотре. Просмотрены список, модальное окно, первый вопрос с 0% и 25%, результат и прокрутка, а также фокус на фильтре с клавиатуры. На экране 1280×720 устранены обрезание названий, высота таблицы и расположение подписи фильтра.
- Список сравнен с предоставленным скриншотом подключения вакансий при 2557×1249, масштаб браузера 1: граница боковой панели — 338 px, таблица начинается на x=370, y=153; в референсе это приблизительно x=338 и x=371, y=157. Пропорции колонок скорректированы. Действия «Подключить», карточки боковой панели и метки из другого процесса не воспроизводились. Доступа к работающей авторизованной «Искре» нет, поэтому точное совпадение её внутренних компонентов и состояний не подтверждено.
- Модальное окно «Основное» просмотрено при ширине 390×844: окно помещается в экран; отдельного мобильного референса нет. Ошибки консоли при осмотре списка не обнаружены. Состояния записи, её успешного завершения и ошибки на реальном устройстве, а также все сочетания размера, наведения и уменьшения движения не проверены.
