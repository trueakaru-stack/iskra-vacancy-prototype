# Решения и открытые вопросы

## Принятые решения

- Результат сценария — редактируемое описание вакансии.
- Четыре вопроса показываются по одному. Переход вперёд доступен только после непустого ответа; возврат сохраняет текст.
- Круг вокруг микрофона показывает заполненность: 25% за каждый непустой ответ. Смысловая оценка не выполняется.
- Запись завершается по нажатию кнопки остановки. В интерфейсе различаются запись, обработка, успешное распознавание и ошибка.
- При ошибках обработки введённый текст не удаляется; доступен ручной ввод и, когда возможно, повторная обработка или запись.
- Для зарплаты допускается одна или обе границы диапазона. Опыт выбирается одним значением; занятость, формат, график и оформление — несколькими.
- Описание проверяется и редактируется человеком. Неизвестные сведения не должны добавляться как факты.
- В текущей реализации черновик доступен в пределах вкладки; сохранение в системе и публикация не подключены.

## Открытые вопросы для интеграции

- Контракт подключения голосового помощника и сервиса генерации действующего продукта.
- Сохранение черновика, авторизация и требования к обработке данных.
- Критерии смысловой полноты ответов, если такая оценка потребуется.
- Дополнительная визуальная проверка всех состояний интерфейса, включая обработку и ошибки.
