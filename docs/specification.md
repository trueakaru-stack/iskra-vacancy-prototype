# Спецификация: создание описания вакансии

Версия 0.5 утверждена пользователем 4 ноября 2026 года. При уточнении пользователь исключил кнопку и процесс «Подключить»: исходный экран является визуальным референсом другого процесса. Поправки от 4 ноября: пользователь согласовал отправку записи в Cloudflare после «Стоп» и позже прямо попросил обновить оформление модального окна и добавить степпер этапов.

## Назначение

Пользователь создаёт черновик вакансии, отвечает на четыре заранее заданных вопроса и получает редактируемое описание. Выходом является описание вакансии: слово «резюме» в максимальном критерии тестового пользователь счёл опечаткой.

## Экран и оформление

Светлая тема, чёрные акценты. Слева находятся шапка «Искры» и пункт «Все вакансии»; справа — заголовок, поиск, фильтр региона, кнопка «Добавить вакансию» и таблица. Колонки таблицы: название, регион, отклики, обработано, истекает. Данные таблицы демонстрационные; неизвестные показатели нового черновика отображаются как «—».

Кнопка добавления открывает модальное окно с затемнением и размытием фона. Этапы: основное, условия, описание вакансии, проверка результата; их показывает информационный степпер NeoBook. Переход выполняют кнопки «Назад» и «Далее». Неизвестные условия можно оставить незаполненными. Шапка и подвал окна без разделительных линий и серой подложки; заголовки и крестик достаточно крупные. Поля визуально согласованы с поиском на странице и не растягиваются вручную. Сглаженный контур берётся из подтверждённой реализации ConfirmDialog Product Catalog; без поддержки `corner-shape` браузер отображает обычные скруглённые углы. Используются компоненты NeoBook и подтверждённые особенности предоставленных референсов; реальный интерфейс авторизованной «Искры» недоступен.

## Четыре вопроса

1. Какие две-три задачи ежедневно он выполняет?
2. Над каким проектом он работает эти 6 месяцев?
3. В ближайшие полгода он продолжит работать над этим проектом или возьмётся за другой? Какой именно?
4. Какими особыми инструментами, программами и знаниями он должен владеть, чтобы эффективно выполнять свою работу?

В каждый момент показан один вопрос и лейбл «Вопрос N из 4», без отдельного степпера вопросов. Степпер над содержимым относится к этапам создания вакансии. Доступна одна кнопка голосового ввода и редактируемое текстовое поле. «Далее» переводит к следующему вопросу только после непустого ответа. «Назад» возвращает к предыдущему ответу, сохраняя введённый текст. После последнего ответа начинается подготовка описания для проверки.

## Прогресс и состояния

Непрерывный круг расположен вокруг кнопки микрофона и заполняется на 25% за каждый непустой после удаления пробельных символов ответ. При редактировании и удалении текста прогресс пересчитывается. Значение не является семантической оценкой ответа.

Во время записи кнопка меняется на «Стоп» и показывается звук. После нажатия «Стоп» отображается обработка; при успешном распознавании показывается галочка без дополнительной видимой подсказки. Если голос не распознан, появляется восклицательный знак и понятное сообщение. Уже полученный текст сохраняется; запись можно повторить или ответить вручную. Отказ в доступе к микрофону и отсутствие поддержки браузера не препятствуют ручному вводу.

В блоке вопроса используется серая подпись номера, обычное начертание вопроса и поле ответа со скруглёнными углами. Контурная иконка микрофона расположена внутри круга прогресса. Более контрастная граница поля сохранена по отдельному решению пользователя.

## Результат

На основе ответов формируются редактируемые блоки «Основные обязанности», «О проекте», «Планы на полгода», «Требования и ключевые навыки». Условия и преимущества добавляются только из введённых данных. Неуказанные факты, например зарплата или опыт, не выдумываются.

Во время генерации кнопка показывает «Создаём описание» и индикатор; при включённом системном уменьшении движения текст остаётся видимым, а анимация останавливается. При ошибке генерации ответы сохраняются и доступна повторная попытка. Сохранённый черновик появляется в демонстрационной таблице и открывается для редактирования в течение текущего сеанса. Публикация на внешних площадках и доступ к настоящей «Искре» не входят в прототип.

## Приёмка

Проверить поиск и регион; открытие и закрытие окна; переходы, клавиатурный фокус и ответы из пробелов; прогресс 0, 25, 50, 75 и 100%, возврат и удаление текста; успешную и неуспешную запись, отказ доступа и ручной ввод; генерацию, её ошибку и редактирование результата. Отдельно сравнить итоговый интерфейс с предоставленными скриншотами в реальном браузере.

## Контракт для разработки

Данные черновика: `title`, `region`, `experience`, границы зарплаты, занятость, формат, график, оформление, преимущества, предложение и `answers` с ключами `tasks`, `project`, `plans`, `skills`. При сохранении название после удаления пробелов обязательно. Остальные реквизиты могут быть пустыми. Черновик и отредактированные секции хранятся только в памяти текущей вкладки; после обновления они исчезают. Значения, которых пользователь не вводил, не подставляются.

На каждом вопросе показывается один текстовый ответ. Переход «Далее» недоступен, пока ответ состоит только из пробелов. После последнего ответа запускается генерация. «Назад» сохраняет изменения и возвращает к предыдущему вопросу, а с первого вопроса — к условиям. Пока идёт запись, обработка или генерация, смена вопроса и закрытие окна недоступны. В случае ошибки генерации текущий ответ не очищается и доступна повторная попытка.

Состояния записи: ожидание; запрос доступа к микрофону; запись с индикатором реальной громкости и действием «Стоп»; обработка; успех с галочкой; ошибка с `!` и пояснением. После «Стоп» аудио передаётся в Cloudflare Workers AI, а распознанная речь добавляется к уже введённому тексту. Приложение не сохраняет аудио на сервере. При ошибке обработки исходный текст сохраняется, запись остаётся во вкладке для повторной попытки; при отсутствии разрешения, поддержки, речи или сети пользователь может продолжить вручную. Анимация учитывает системную настройку уменьшения движения.

Worker принимает `POST /generate` с JSON вида `{ "title": "...", "answers": { "tasks": "...", "project": "...", "plans": "...", "skills": "..." } }`. Четыре ответа обязательны; каждый ограничен 4000 символами, заголовок — 200, тело запроса — 50000 байт. При превышении длины ответа интерфейс предлагает его сократить и не даёт перейти дальше. Успех: `{ "sections": { "tasks": "...", "project": "...", "plans": "...", "skills": "..." } }`; ошибка: `{ "error": "..." }` с соответствующим HTTP-статусом. Клиент при ошибке не удаляет данные. Модель возвращает только четыре редактируемых раздела, проверка структуры не заменяет проверку фактов человеком. Запрещено выдавать шаблонный результат за ответ модели.

Для речи Worker принимает `POST /transcribe` с аудиозаписью до 2 МиБ, передаёт её модели Whisper с указанием русского языка и возвращает `{ "text": "..." }`. При неудачной обработке клиент хранит запись только в памяти текущей вкладки для повторной отправки. При достижении ограничения запись останавливается; перед обработкой требуется повторное действие пользователя. После успеха, сброса или закрытия окна запись из памяти удаляется.

Отображаются реальные состояния интерфейса: загрузка и ошибки не имитируют успешную операцию. Для ранее существовавших демонстрационных строк показываются данные с предоставленного референса; у новых черновиков неизвестные показатели не выдумываются. Процесс подключения вакансий и кнопка «Подключить» не воспроизводятся.
