# Объём и приоритеты

## Сделано

- Голосовой и текстовый ввод основных сведений, условий и четырёх ответов.
- Реальное распознавание, распределение по полям и контекстное наполнение кратких ответов.
- Генерация четырёх структурированных разделов описания вакансии.
- Обязательные ответы, переходы назад и через закреплённый степпер, круг по 25%.
- Явные состояния записи, обработки и ошибки с сохранением введённого текста.
- Проверка и ручная коррекция всех полей и разделов, защита ручных правок при генерации.
- Просмотр вакансии в основной области, голосовая правка с предварительным просмотром и отменой.
- Таблица с поиском, фильтром, сортировкой, подсветкой новой строки и удалением.
- Сохранение созданных вакансий, правок и удалений после обновления браузера.
- Спецификация, пользовательская презентация, объяснение решений, инструкции для ИИ и отчёт о проверках.

## Что оставлено за пределами реализации

| Область | Причина решения |
| --- | --- |
| Интеграция с действующим продуктом и общее хранилище | Нет тестового доступа, контрактов внутреннего сервиса и полномочий работать с данными организации. |
| Публикация вакансии на внешних площадках | Для проверки создания достаточно сохранить результат. Нужны отдельные права и интеграции. |
| Полное восстановление архитектуры продукта | Публичные материалы показывают только часть экранов. Выдуманная структура создала бы ложную уверенность. |
| Отдельный скоринг полноты ответа | Семантическое наполнение реализовано через контекстное раскрытие. Дополнительная оценка потребовала бы критериев и набора примеров. |
| Исследование с реальными заказчиками | Не было доступа к участникам. Ускорение и удобство ещё не подтверждены измерениями. |
| Дополнительные темы и расширенная оболочка | При ограничении в одни сутки приоритет имеют рабочий голосовой сценарий, ошибки и проверяемый результат. |

## Критерии результата

Наполненность ответа проверяется по непустому тексту. Семантическое наполнение выполняет модель при подготовке содержательного черновика. По полученным ответам она генерирует структурированный текст описания вакансии. Это три наблюдаемых результата внутри одного процесса. Их наличие не означает безошибочность любого сгенерированного текста: перед сохранением предусмотрена проверка человеком.

## Последовательность приоритетов

Сначала разобрать входные требования и риск потери данных. Затем обеспечить голосовой ввод, переходы и обратную связь. После этого подключить генерацию и проверку результата. Далее добавить сохранение и необходимые операции с вакансией. Оболочку и визуальные детали уточнять по проверке основного сценария. В финале сверить материалы с фактической реализацией.
