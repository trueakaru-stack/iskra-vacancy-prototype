# Работа с ИИ и последовательность

Сначала изучены тестовое задание, публичные материалы «Искры», предоставленные изображения и исходники NeoBook. Затем согласованы спецификация, границы прототипа, один вопрос на экране, правило 25% за непустой ответ и состояния голосового ввода. После утверждения выполнялись реализация и проверки.

Пользователь определял продуктовые решения и утверждал требования. ИИ помогал на всех пяти этапах работы: исследование, спецификация, реализация, проверки и подготовка передачи. Это 100% покрытия этапов, а не измеренная доля трудозатрат. Точный процент времени участия ИИ не измерен; его нельзя надёжно вывести из объёма кода. Финальные решения о представлении работы и проверка её смысла остаются за автором тестового.

Для генерации используется системная инструкция из `worker/src/index.ts`. Её смысл: сформировать четыре текстовых блока на русском, использовать только переданные факты, не добавлять неуказанные зарплату, сроки, опыт, обязанности, требования или условия, вернуть JSON с ключами `tasks`, `project`, `plans`, `skills`. Данные пользователя передаются отдельно от инструкции. Worker проверяет формат результата, но не может гарантировать отсутствие вымышленных моделью фактов: человек проверяет описание перед сохранением.

Распознавание речи выполняется механизмом браузера; оно не является генерацией текста вакансии моделью Qwen. Опциональная семантическая оценка полноты ответа не реализована: в пределах срока приоритет отдан работающему вводу, ясным ошибкам и проверяемому результату.
