# Создание описания вакансии голосом

Новая функция помогает подготовить описание вакансии по ответам на четыре вопроса. Голосовой помощник переводит речь в текст, затем из ответов формируется черновик. Его можно проверить, исправить и сохранить.

[Открыть демонстрацию](https://trueakaru-stack.github.io/iskra-vacancy-prototype/)

## Как это работает

1. В списке вакансий нажмите «Добавить вакансию» и укажите известные сведения.
2. В разделе «Описание вакансии» ответьте на четыре вопроса по очереди: продиктуйте ответ или введите его вручную.
3. Проверьте распознанный текст. Кнопки «Назад» и «Далее» позволяют перейти между вопросами; круг показывает заполненность ответов.
4. Создайте описание, отредактируйте разделы и сохраните черновик.

При ошибке записи или обработки введённый текст сохраняется; доступен ручной ввод и, в зависимости от ошибки, повторная отправка записи или новая запись. Круг показывает наличие ответа, а не его смысловую полноту.

## Границы демонстрации

Демонстрация воспроизводит сценарий отдельно от действующего продукта. Для работы внутри продукта потребуется интеграция с его голосовым помощником и системой хранения. Черновики в демонстрации находятся в памяти вкладки и удаляются после её обновления или закрытия; публикация вакансий не выполняется.

Для записи нужны разрешение на микрофон и подключение к сети. После остановки запись и, при создании описания, текстовые ответы передаются подключённому сервису обработки. Приложение не сохраняет аудиозапись на сервере. Используйте вымышленные сведения: результат генерации необходимо проверить перед применением.

## Запуск и проверка

Нужны Node.js не ниже 22 и pnpm 11.25. Команды выполняются из корня проекта:

    pnpm install --frozen-lockfile
    pnpm test
    pnpm run typecheck
    pnpm run build

Адрес сервиса обработки задаётся переменной `VITE_GENERATION_URL`. Перед использованием с реальными данными необходимо согласовать подключение, доступ, обработку данных и сохранение вакансий с продуктовой системой.
